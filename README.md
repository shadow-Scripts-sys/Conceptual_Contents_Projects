ESP32 Projects
A collection of small ESP32 / Arduino projects. Each folder is a standalone project with its own code and README.

Getting Started
Download and Open the project folder you want in Arduino IDE.
Follow that project's own README for wiring, libraries, and upload steps.

Requirements
Arduino IDE (or PlatformIO)
ESP32 Arduino Core installed via Boards Manager
Libraries are listed per project (see each folder's README)
